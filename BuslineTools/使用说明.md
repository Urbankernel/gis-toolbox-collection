# 公交线路工具箱（BuslineTools）使用说明

## 一、简介

本工具箱在 ArcGIS / ArcGIS Pro 中以图形界面方式，按**城市**从高德地图抓取公交（地铁）线路、站点与轨迹，输出**线路 LineString + 站点 Point 双图层**（SHP / GeoPackage）。

核心能力：

- **三种检索模式**：指定线路（`lines`）/ 只搜关键词（`only`）/ 数字穷举全量（`full`），覆盖「抓已知线路、按词抓取、批量路号、全量穷举」四类需求；
- **前缀 / 后缀 / 额外关键词**组合：如「浦东 + 1~30 + 路」批量生成「浦东1路~浦东30路」；
- **多 Key 轮换 + 限速**：自动处理 key 失效、日配额耗尽、QPS 临时限流；
- **自动去重**：线路按规范化名称、站点按复合键，双重兜底；
- **统一 WGS-84** 输出。

## 二、环境要求

| 依赖 | 说明 |
| --- | --- |
| ArcGIS Pro（arcgispro-py3 环境） | 自带 `arcpy`、`requests` |
| `shapely` | 需额外安装，用于线路轨迹 / 站点几何构建 |

安装 `shapely`（需在 **ArcGIS Pro 的 Python 环境**中执行，请用管理员权限打开命令行）：

```powershell
cd "C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3"
python -m pip install shapely
```

> 注意：不要装到用户目录（`--user`）——ArcGIS Pro 后台进程不加载用户 site-packages，会导致运行时仍报 `ModuleNotFoundError: shapely`。

## 三、目录结构

## 四、在 ArcGIS Pro 中加载

用下面任一方式加载（推荐方式二）：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `BuslineTools` 目录，双击 `BuslineTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `BuslineTools/BuslineTools.pyt`。

加载后双击 **「公交线路抓取」** 打开参数面板，填好参数点击 **运行**，进度实时显示在「地理处理 → 消息」中。

## 五、参数说明

### 5.1 检索

| # | 参数名 | 显示名 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | city | 城市 | 是 | — | 城市名，如 `上海` |
| 2 | api_keys | 高德 Web 服务 Key（可多选） | 是 | — | 多个 Key 自动轮换 |
| 3 | search_mode | 检索模式 | 是 | lines | `lines` 指定线路 / `only` 只搜关键词 / `full` 数字穷举 |
| 4 | lines | 指定线路（逗号分隔） | lines 模式 | — | 如 `406路,102路` |
| 5 | only | 关键词（only 模式） | only 模式 | — | 如 `机场`，命中所有含该词的线路 |
| 6 | prefix | 线路名前缀（逗号分隔） | 否 | — | 如 `浦东` |
| 7 | suffix | 数字后缀（仅穷举，逗号分隔） | 否 | — | 如 `路` |
| 8 | extra | 额外关键词（仅穷举，逗号分隔） | 否 | — | 穷举末尾追加，如 `机场,旅游` |
| 9 | max_num | 穷举上限 | full 模式 | 1000 | 数字穷举 1~max_num |
| 10 | exact | 精确检索（只留短名全等） | 否 | False | 开启后只保留短名与关键字严格全等的线路 |

> 高德 Key 申请：[高德开放平台](https://lbs.amap.com/) → 创建应用 → 服务平台选「Web 服务」。公交线路关键字 API 免费额度 5000 次/日、并发上限 30 次/秒。

### 5.2 请求

| # | 参数名 | 显示名 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 11 | max_qps | 每秒请求数上限 | 28.0 | 硬上限 30，内置限速 |
| 12 | delay | 每次请求间隔（秒） | 0.0 | 在 QPS 限速外进一步降低频率 |
| 13 | offset | 每页条数 | 20 | 单次请求返回条数 |
| 14 | timeout | 请求超时（秒） | 15.0 | 单次请求超时 |
| 15 | retries | 单请求最大重试 | 3 | 失败自动重试 |

### 5.3 输出

| # | 参数名 | 显示名 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 16 | output_lines | 线路要素类 | 是 | — | `.shp` / `.gpkg`，线要素 |
| 17 | output_stops | 站点要素类 | 是 | — | `.shp` / `.gpkg`，点要素 |
| 18 | output_crs | 输出坐标系 | 否 | GCS_WGS_1984 | 目标投影；WGS-84 则不投影 |

> 线路与站点填**同一个 .gpkg** 路径时，会写入同一文件的 `busline`、`busstop` 两个图层；填不同路径则各自独立输出。

## 六、快速上手

**示例 1：抓指定几条线路（最常用）**

1. 城市 → `上海`；
2. 检索模式 → `lines`，指定线路 → `406路,102路`；
3. 高德 Key → 填入 Web 服务 Key；
4. 线路要素类 → `D:\data\busline.gpkg`，站点要素类 → `D:\data\busline.gpkg`（同文件双图层）；
5. 运行。

**示例 2：按关键词抓机场线**

1. 检索模式 → `only`，关键词 → `机场`；
2. 其余同上，运行后拿到「机场一线~机场七线」等含「机场」的全部线路。

**示例 3：数字穷举抓地铁线**

1. 检索模式 → `full`，前缀 → `地铁`，后缀 → `号线`，穷举上限 → `10`；
2. 运行 → 生成「地铁1号线~地铁10号线」关键字逐条检索。

## 七、输出说明

运行成功后生成 **两个图层**：

| 图层 | 几何 | 说明 |
| --- | --- | --- |
| 线路 | LineString | 公交/地铁线路轨迹（WGS-84） |
| 站点 | Point | 各线路站点（WGS-84） |

### 7.1 线路属性字段（21 个）

`line_name`（短名）、`route_id`、`route_name`（完整名，含起终点方向）、`type`、`polyline`（GCJ-02 原始坐标串）、`polyline_wgs84`（WGS84 坐标串）、`citycode`、`start_stop`、`end_stop`、`start_time`、`end_time`、`uicolor`、`timedesc`（发车时刻表，已解码 JSON）、`loop`、`status`、`direc`、`company`、`distance`、`basic_price`、`total_price`、`bounds`。

### 7.2 站点属性字段（11 个）

`line_name`、`route_id`、`route_name`、`station_id`、`station_name`、`station_index`、`location`、`lng` / `lat`（GCJ-02 原始）、`lng_wgs84` / `lat_wgs84`（WGS84）。

> 说明：高德同一条线路的上下行各返回一条独立记录（独立 `route_id`，`route_name` 含起终点方向），站点通过 `route_id` 关联到具体方向，本工具原样保存、不做聚合。

### 7.3 SHP 与 GPKG 的区别

| 项目 | SHP | GPKG |
| --- | --- | --- |
| 字段名 | 超过 10 字符自动映射 | 保留原字段名 |
| 文本长度 | 最长 254 字符 | 更长 |
| 数据结构 | 多文件 | 单文件（可含多图层） |

SHP 超长字段名映射：`polyline_wgs84→line_wgs84`、`basic_price→base_price`、`total_price→total_pric`、`station_name→stn_name`、`station_index→stn_index`。

## 八、常见问题（FAQ）

**Q1：运行报 `ModuleNotFoundError: shapely`？**
shapely 未装到 ArcGIS Pro 的 Python 环境，按「二、环境要求」在管理员命令行安装。

**Q2：运行报 `ModuleNotFoundError: geo_common` / `busline_core`？**
目录结构被破坏，请保持 `BuslineTools` 与 `geo_common` 同级（见「三、目录结构」）。

**Q3：结果没落到指定路径？**
本工具强制前台执行以保证路径可靠，请确认「地理处理 → 选项」未强制后台。

**Q4：抓到的线路数量偏少？**
- 高德公交接口是**模糊匹配**，可调大 `max_num` 或补充 `extra` 关键词；
- 检查是否勾选了「精确检索」（会过滤掉短名不完全匹配的线路）；
- 日配额用尽（5000 次/日）会导致后续 key 停用，建议多填几个 Key。

**Q5：站点坐标看起来有偏移？**
输出已统一为 WGS-84。若叠加在带偏移的底图上，请确认底图坐标系一致；原始 GCJ-02 坐标保留在 `lng`/`lat` 字段供核对。
