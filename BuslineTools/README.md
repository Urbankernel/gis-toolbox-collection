# BuslineTools · 公交线路抓取

按城市抓取公交**线路 + 站点**双图层。支持三种检索模式（指定线路 / 关键词 / 前缀穷举）。

- 数据源：高德 `/v3/bus/linename`（REST，**需自备 Key**）
- 输出：线路线要素类 + 站点点要素类（`.shp` / `.gpkg`，WGS-84）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `BuslineTools` 目录，双击 `BuslineTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `BuslineTools/BuslineTools.pyt`。

## 参数

| 参数 | 说明 |
|---|---|
| 城市 | 城市名 |
| 高德 Web 服务 Key | 多 Key 用分号分隔 |
| 检索模式 | `lines`（指定线路）/ `only`（关键词）/ `full`（前缀穷举） |
| 指定线路 | `lines` 模式，逗号分隔 |
| 关键词 | `only` 模式 |
| 线路名前缀 | `full` 模式，逗号分隔 |
| 数字后缀 | `full` 模式，穷举数字 |
| 额外关键词 | `full` 模式 |
| 穷举上限 | `full` 模式最大数量 |
| 精确检索 | 只留短名全等 |
| 每秒请求数上限 / 间隔 / 每页条数 / 超时 / 重试 | 限速与容错 |
| 线路要素类 | 输出（`.shp` / `.gpkg`） |
| 站点要素类 | 输出（`.shp` / `.gpkg`） |
| 输出坐标系 | 默认 WGS-84 |

## 输出

- 线路线要素类（约 21 字段）+ 站点点要素类（约 11 字段）
- 去重：线路按规范化 `route_name`，站点按 `(route_name, station_index, station_name)` 复合键
- 坐标统一 WGS-84

## 数据源与许可

高德 REST API，需自备 Key，遵守高德服务条款与配额。
