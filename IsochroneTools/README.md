# IsochroneTools · 等时圈 / 可达性

从出发点在研究区内计算**等时圈**：输出**等时带面矢量**（可达范围分层）+ **时间表面栅格**（每栅格=到达所需分钟）。

- 数据源：百度批量算路 + 腾讯距离矩阵（**双引擎**，需自备 Key）
- 输出：等时带面（`.shp`/`.gpkg`）+ 时间表面栅格（`.tif`，WGS-84）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `IsochroneTools` 目录，双击 `IsochroneTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `IsochroneTools/IsochroneTools.pyt`。

## 参数

### 工具 1：生成等时圈

| 参数 | 说明 |
|---|---|
| 出发点要素类（点） | 支持多点 |
| 研究区面要素类 | 研究范围 |
| 算路引擎 | 百度 / 腾讯 |
| 出行方式 | 驾车 / 步行 / 骑行等 |
| 驾车策略（仅百度驾车） | 0~11 |
| 等时带阈值（分钟） | 逗号分隔，如 `5,10,15,30` |
| 渔网间距（米） | 终点网格密度 |
| 栅格分辨率（米） | 时间表面栅格 |
| 百度 AK / 腾讯 key | 多 Key 用分号分隔 |
| QPS | 每秒请求数 |
| 输出等时带面 | `.shp` / `.gpkg` |
| 输出时间表面栅格 | `.tif` |
| 输出渔网终点 / 不可达点 | 可选 |
| 工作目录 | 断点续跑，可选 |

### 工具 2：干跑估算

| 参数 | 说明 |
|---|---|
| 出发点要素类 / 研究区面要素类 | 同工具 1 |
| 算路引擎 | 百度 / 腾讯 |
| 渔网间距 / QPS | 估算请求量与耗时 |

## 输出

- 等时带面：按阈值分层（字段含阈值分钟数），WGS-84
- 时间表面栅格：单波段，值=到达分钟，带 WGS-84 坐标系

## 数据源与许可

百度批量算路 / 腾讯距离矩阵，官方 API，需自备 Key。

> ⚠️ 腾讯驾车距离矩阵个人额度用完会**单独冻结**（报 121「每日调用量已达上限」），且非每日重置，需在控制台提升额度或换 Key。
