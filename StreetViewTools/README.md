# StreetViewTools · 百度街景下载

从本地路网批量生成采样点，再按采样点下载百度街景全景图。

- 数据源：百度全景**逆向接口**（`mapsv0.bdimg.com` 的 `qt=qsdata/pdata/sdata`，**无需 AK**）
- 输出：街景 JPG + 下载报告点要素类

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `StreetViewTools` 目录，双击 `StreetViewTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `StreetViewTools/StreetViewTools.pyt`。

## 参数

### 工具 1：生成采样点

| 参数 | 说明 |
|---|---|
| 路网要素类（线） | 本地路网线 |
| 研究区要素类（面） | 可选，裁剪采样范围 |
| 采样间距（米） | 沿路等间距 |
| 端点偏移（米） | 避开路口 |
| 输出采样点要素类 | `.shp` / `.gpkg`（含 point_id/street_id/bearing/lat/lon） |

### 工具 2：批量下载街景

| 参数 | 说明 |
|---|---|
| 采样点 CSV / 点要素类 | 二选一输入 |
| 采样点坐标系 | 仅 CSV 生效：wgs84/gcj02/bd09 |
| 下载模式 | 全景 / 4 方向切片 |
| 清晰度 | 1~4 |
| 裁剪底部 / 顶部比例 | 去除水印/天空 |
| 就近搜索半径（米） | 采样点匹配最近全景 |
| 请求间隔 / 超时 / 重试 | 限速与容错 |
| 输出图片目录 | 街景 JPG 存放处 |
| 下载报告要素类 | `.shp` / `.gpkg` |

## 输出

- 街景 JPG（每采样点 1~5 张：左/右/前/后/全景）
- 下载报告点要素类，含 `point_id/status/panoid/road_name/shot_date/car_heading` 及 5 个 `img_*` 字段
- 坐标统一 WGS-84
