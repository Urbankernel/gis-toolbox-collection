# StreetViewTools 使用说明

百度街景批量下载工具箱（ArcGIS Pro Python Toolbox）。

从本地路网生成采样点，再按采样点批量下载百度街景图片（逆向接口，**无需 AK**），
输出街景 JPG 图片 + 下载报告点要素类（含图片路径，可在 Pro 地图中点击查看对应街景）。

---

## 一、简介

工具箱包含 **2 个工具**，串成一条闭环：

```
路网线要素类 ──[工具1 生成采样点]──> 采样点点要素类 ──[工具2 批量下载街景]──> 街景 JPG + 下载报告点要素类
```

| 工具 | 作用 | 输入 | 输出 |
| --- | --- | --- | --- |
| 生成采样点 | 沿路等间距生成采样点 + 算街道走向 bearing | 路网线要素类（+ 可选研究区面） | 采样点点要素类（WGS84） |
| 批量下载街景 | 按采样点下载街景图片 | 采样点 CSV 或 点要素类 | 街景 JPG（目录）+ 下载报告点要素类 |

---

## 二、环境要求

- **ArcGIS Pro**（arcgispro-py3 环境）
- **零新增第三方依赖**：本工具只用到 `Pillow`、`requests`、`numpy`、`shapely`，
  均为 ArcGIS Pro 自带或已安装。**无需 `pip install` 任何东西**。

> 对比原开源项目（依赖 geopandas / folium / pyrosm / osmnx），本工具已把这些重依赖全部砍掉，
> 用 arcpy + shapely 替代，改造成本极低、环境更干净。

---

## 三、目录结构

```
github_arcgis_tools/
├── geo_common/               # 共享库（coords 坐标转换 / exporter 写要素类）
└── StreetViewTools/
    ├── StreetViewTools.pyt    # 工具箱入口（2 个工具）
    ├── streetview_core/       # 核心包
    │   ├── bearing.py         # 街道走向方位角计算
    │   ├── pano_slice.py      # 全景裁剪 + 切视角
    │   ├── pano_client.py     # 百度逆向接口客户端
    │   ├── sampling.py        # 采样点生成（arcpy + shapely）
    │   ├── download.py        # 下载主流程
    │   └── writer.py          # 写采样点 / 报告要素类
    └── 使用说明.md
```

**注意**：`geo_common` 目录必须与 `StreetViewTools` 目录保持同级（都在 `github_arcgis_tools/` 下）。

## 四、在 ArcGIS Pro 中加载

用下面任一方式加载（推荐方式二）：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `StreetViewTools` 目录，双击 `StreetViewTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `StreetViewTools/StreetViewTools.pyt`。

展开后可见「生成采样点」「批量下载街景」两个工具，双击工具填写参数运行。

## 五、参数说明

### 工具 1：生成采样点（SamplePoints）

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 路网要素类（线） | DEFeatureClass | ✅ | — | 本地矢量路网（shp / gpkg / geojson），线要素 |
| 研究区要素类（面，可选） | DEFeatureClass | — | — | 提供时采样后仅保留研究区内的点 |
| 采样间距（米） | GPLong | — | 40 | 沿路采样点的间距 |
| 端点偏移（米） | GPLong | — | 15 | 路段两端各留多少米不采样（避开路口） |
| 输出采样点要素类 | DEFeatureClass | ✅ | — | `.shp` 或 `.gpkg` |

**输出字段**：`point_id`（唯一标识）、`street_id`（溯源路网）、`bearing`（街道走向 [0,180)）、`lat` / `lon`（WGS84）。

### 工具 2：批量下载街景（DownloadStreetView）

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 采样点 CSV（可选） | DEFile | 二选一 | — | `name,lng,lat[,bearing]` |
| 采样点点要素类（可选） | DEFeatureClass | 二选一 | — | 工具 1 的输出可直接作为本工具输入 |
| 采样点坐标系 | GPString | — | wgs84 | `wgs84` / `gcj02` / `bd09`（仅 CSV 输入时生效） |
| 下载模式 | GPString | — | 4_views | `4_views` / `left_right` / `front_back` / `panorama` |
| 清晰度（1~4） | GPLong | — | 3 | 3=4096×2048；4=8192×4096（4 倍存储，一般无收益） |
| 裁剪底部比例 | GPDouble | — | 0.4 | 裁掉全景底部采集车顶；设 0 关闭 |
| 裁剪顶部比例 | GPDouble | — | 0.0 | 裁掉顶部天空；与底部之和须 < 1 |
| 就近搜索半径（米） | GPDouble | — | 5.0 | 坐标本身无街景时就近搜索兜底；设 0 关闭 |
| 请求间隔（秒） | GPDouble | — | 0.3 | 瓦片级间隔，避免触发服务端风控，不建议调更低 |
| 请求超时（秒） | GPDouble | — | 30 | — |
| 单请求最大重试 | GPLong | — | 2 | — |
| 输出图片目录 | DEFolder | ✅ | — | 街景 JPG 落盘目录 |
| 下载报告要素类 | DEFeatureClass | ✅ | — | `.shp` 或 `.gpkg` |

**下载模式说明**：

| 模式 | 说明 |
| --- | --- |
| `4_views` | 左 / 右 / 前 / 后四方向照片（默认） |
| `left_right` | 只下左右（垂直街道方向） |
| `front_back` | 只下前后（沿街道方向） |
| `panorama` | 完整 360° 全景图（单张） |

## 六、快速上手

### 示例 1：从路网到采样点

1. 准备一份路网线要素类（如 `roads.gpkg`，需带坐标系）；
2. 运行「生成采样点」，路网选 `roads.gpkg`，间距 40、偏移 15；
3. 输出选 `samples.gpkg`，得到采样点点要素类。

### 示例 2：直接下载街景（跳过采样）

1. 新建一个 `points.csv`：

   ```csv
   name,lng,lat,bearing
   同济大学,121.506,31.285,90
   外滩,121.490,31.240,0
   ```

2. 运行「批量下载街景」，采样点 CSV 选该文件，输出图片目录选一个文件夹，
   报告选 `report.gpkg`，其余保持默认；
3. 运行后：图片目录里出现 `同济大学_xx路_20240501_front.jpg` 等照片，
   `report.gpkg` 里每个点按视角带 `img_left` / `img_right` / `img_front` / `img_back`
   字段，在 Pro 里逐字段点开即可看对应方向街景。

### 示例 3：两步串联

1. 工具 1 从路网生成 `samples.gpkg`；
2. 工具 2 的「采样点点要素类」直接选 `samples.gpkg` 的 `points` 图层（或选该 gpkg），即可下载。

## 七、输出说明

### 街景图片（图片目录内）

- 四视角：`{point_id}_{路名}_{拍摄日期}_{view}.jpg`（view ∈ left/right/front/back）
- 全景：`{point_id}_{路名}_{拍摄日期}_pano.jpg`
- 路名 / 拍摄日期为可选段，缺失则省略
- `download_report.csv`：每点状态、panoid、路名、拍摄日期、采集车朝向等

### 下载报告要素类

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| point_id | TEXT | 采样点唯一标识 |
| status | TEXT | `ok` / `no_pano` / `download_failed` |
| lat / lon | DOUBLE | WGS84 坐标 |
| panoid | TEXT | 全景唯一标识 |
| road_name | TEXT | 路名 |
| shot_date | TEXT | 拍摄日期 |
| car_heading | DOUBLE | 采集车朝向（度） |
| img_left | TEXT | 左视角图片路径（Pro 中可点击查看） |
| img_right | TEXT | 右视角图片路径 |
| img_front | TEXT | 前视角图片路径 |
| img_back | TEXT | 后视角图片路径 |
| img_pano | TEXT | 全景图路径（仅 `panorama` 模式） |
| message | TEXT | 就近匹配距离等附加信息 |

按下载模式填充对应字段：`4_views` 填 left/right/front/back 四列；`left_right` 填
left/right 两列；`front_back` 填 front/back 两列；`panorama` 只填 img_pano 一列；其余
列留空。

**SHP 字段名映射**：`car_heading` 超 10 字符，SHP 下自动映射为 `car_head`；GPKG 保留原名。
`img_left` / `img_right` / `img_front` / `img_back` / `img_pano` 均 ≤10 字符，两种格式字段名一致。

### 断点续跑

某点目标图已齐全即跳过，`no_pano` 点无文件、下次重跑自动再试。报告 CSV 会被覆盖刷新。

## 八、常见问题（FAQ）

**Q1：报 `ModuleNotFoundError: geo_common`？**
A：确认 `geo_common` 目录与 `StreetViewTools` 目录同级。若仍报错，重启 ArcGIS Pro 一次
（后台进程会缓存旧模块，改过 `geo_common` 代码后尤其需要重启）。

**Q2：需要装 Pillow / geopandas 吗？**
A：不需要。`Pillow` 已随 ArcGIS Pro 自带，`geopandas` 已被 arcpy + shapely 替代。

**Q3：下载时提示覆盖率低 / 大量 no_pano？**
A：该区域百度全景覆盖不足，属正常。可调大「就近搜索半径」，或检查采样点是否在道路旁。

**Q4：街景图版权合规？**
A：**街景原始影像受百度服务条款约束，仅供研究内部分析，不得对外发布原始影像、不得商业传播。** 逆向接口无 AK、无日配额，但受服务端风控，请保持默认请求间隔、控制批量规模。

**Q5：采样点 CSV 用高德/百度拾取的坐标可以吗？**
A：可以。CSV 输入时把「采样点坐标系」设为 `gcj02`（高德/腾讯）或 `bd09`（百度），工具会自动转 WGS84。点要素类输入则默认已是 WGS84。

**Q6：采样点为什么和路网数字化方向无关？**
A：bearing 做了 canonical 归一化（[0,180)），保证 left/right 不受路网画线方向影响。
