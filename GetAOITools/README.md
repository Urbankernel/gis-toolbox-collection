# GetAOITools · 地名转 AOI 面

把一批地名（如「同济大学」「鲁迅公园」）转换为**兴趣面（AOI 面要素类）**。两段式：先检索地名拿候选，再抠取边界多边形。

- 数据源：高德 `place/text` + `getPoiInfo` / 百度 `place/v2/search` + `qt=ext`（网页端隐藏接口，有反爬）
- 输出：AOI 面要素类（`.shp` / `.gpkg`，约 20 字段，含输入地名溯源）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `GetAOITools` 目录，双击 `GetAOITools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `GetAOITools/GetAOITools.pyt`。

## 参数

| 参数 | 说明 |
|---|---|
| 地名清单 CSV | 每行 `name[,city[,lng,lat]]` |
| 地名清单（TXT） | 每行一个地名（推荐，配合全局城市缩小范围） |
| 数据源 | 高德 / 百度 |
| 高德 Key / 百度 AK | 多 Key 用分号分隔 |
| 全局城市 | 缩小检索范围 |
| 多结果取舍 | 自动 / 首个 / 按关键词 / 最大面 |
| 分支关键词 | `want=keyword` 时用 |
| 分类白名单 | 逗号分隔，排除交通设施/地铁站/停车场等 |
| 最小 / 最大面积（km²） | 面积过滤 |
| 每地名最大候选数 | 候选上限 |
| 请求最小/最大间隔、重试、超时 | 反爬限速与容错 |
| 输出 AOI 面要素类 | `.shp` / `.gpkg` |
| 输出坐标系 | 默认 WGS-84 |
| 边界接口 Cookie / User-Agent | 触发人机验证时兜底 |

## 输出

- AOI 面要素类，含 `input_name`（用户输入地名溯源）、`name`、`adcode`、`districtname`、`tag_show_info` 等约 20 字段
- 坐标统一 WGS-84

## 数据源与许可

高德/百度网页端隐藏边界接口，**未公开、有反爬**。
