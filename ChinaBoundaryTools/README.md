# ChinaBoundaryTools · 行政区边界

按需获取**国 / 省 / 市 / 区县**四级中国行政区边界，输出边界面要素类（`.shp`）+ 可选 GeoJSON。

- 数据源：阿里云 DataV.GeoAtlas（**无需 AK**、无配额）
- 输出：面要素类（`.shp`，WGS-84）+ 可选 GeoJSON

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `ChinaBoundaryTools` 目录，双击 `ChinaBoundaryTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `ChinaBoundaryTools/ChinaBoundaryTools.pyt`。

## 参数

### 工具 1：获取行政区边界

| 参数 | 说明 |
|---|---|
| 行政区层级 | auto / 国 / 省 / 市 / 区县 |
| 行政区名称 | 逗号分隔，如 `广东省,山东省` |
| 行政区编码 adcode | 逗号分隔，如 `440000,370000` |
| 下钻层数 | 0=本级，1=子级，2=孙级，上限 3 |
| 仅取子级 | 不含本级轮廓 |
| 输出边界面要素类 | `.shp` |
| 输出 GeoJSON | 可选，留空不输出 |
| 缓存目录 | 可选，默认关闭 |

### 工具 2：名称解析预览

纯本地字典解析，不发请求，用于确认「名称 → adcode」、查重名歧义。

| 参数 | 说明 |
|---|---|
| 行政区层级 | auto 等 |
| 行政区名称 / 编码 | 逗号分隔 |

## 输出

- 边界面要素类，字段 `adcode/name/level/parent/children/cen_lng/cen_lat`，WGS-84
- 内置行政区划字典（`data/dict.json`，随工具箱打包），支持新旧码双向映射、重名歧义提示、南海十段线默认剔除
