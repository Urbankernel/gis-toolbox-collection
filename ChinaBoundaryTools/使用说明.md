# ChinaBoundaryTools 使用说明

从阿里云 **DataV.GeoAtlas** 按需获取**国 / 省 / 市 / 区县**四级中国行政区边界，输出**边界面要素类（.shp）**与可选 **GeoJSON**，坐标系 **WGS-84（EPSG:4326）**。

改造自开源项目 [Urbankernel/chinaboundary](https://github.com/Urbankernel/chinaboundary)，核心算法（GeoAtlas 客户端、名称↔adcode 解析、递归下钻、几何修复）原样移植，仅把 `geopandas` 导出替换为 `arcpy`（`geo_common.exporter`），做到**零新增第三方依赖**（无需 geopandas）。

## 一、简介

工具箱含 **2 个工具**：

| 工具 | 作用 |
|---|---|
| 获取行政区边界 | 按名称/adcode 获取国/省/市/区县四级边界，输出面要素类 + 可选 GeoJSON |
| 名称解析预览 | 纯本地字典解析「名称 → adcode」，排查重名歧义，不发网络请求 |

**无需任何 AK、无配额限制**。依赖的行政区划字典已随工具箱打包在 `ChinaBoundaryTools/data/dict.json`（v2，3238 条记录），**请勿删除该文件**。

## 二、环境要求

- ArcGIS Pro（自带 arcpy 3.5.2 环境）；
- **无需安装任何第三方库**（geopandas 已被 arcpy + `geo_common.exporter` 替代）。

## 三、目录结构

```
github_arcgis_tools/
├── geo_common/                # 共享库（coords 坐标转换 / exporter 写要素类）
└── ChinaBoundaryTools/
    ├── ChinaBoundaryTools.pyt # 工具箱入口（2 个工具）
    ├── china_boundary_core/   # 核心包（client/resolver/fetch/normalize/store/export/pipeline）
    ├── data/dict.json         # 行政区划字典（随包，勿删）
    └── 使用说明.md
```

## 四、在 ArcGIS Pro 中加载

用下面任一方式加载（推荐方式二）：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `ChinaBoundaryTools` 目录，双击 `ChinaBoundaryTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `ChinaBoundaryTools/ChinaBoundaryTools.pyt`。

工具箱内出现两个工具（按拼音/`self.tools` 顺序显示）：**获取行政区边界**、**名称解析预览**。

## 五、参数说明

### 5.1 工具 1：获取行政区边界

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 行政区层级 | 下拉 | 是 | `auto`（自动推断）/ `country` / `province` / `city` / `district` |
| 行政区名称 | 文本 | 否 | 逗号分隔多值，如 `广东省,山东省`；与 adcode 二选一 |
| 行政区编码 adcode | 文本 | 否 | 6 位编码，逗号分隔多值，如 `440000,370000`；与名称二选一 |
| 下钻层数 | 整数 | 否 | `0`=本级，`1`=直接子级，`2`=孙级，上限 `3`（默认 0） |
| 仅取子级 | 布尔 | 否 | 勾选后不含本级轮廓，常用于「全国 → 34 省」下钻 |
| 输出边界面要素类 | 输出 | 是 | 填 `.shp` 路径（浏览选择，自动补 `.shp` 后缀） |
| 输出 GeoJSON | 文件 | 否 | 可选 `.json` 路径（浏览选择），留空则不输出 |
| 缓存目录 | 文件夹 | 否 | 可选，留空默认关闭；填目录后原始响应按 URL 落盘（TTL 7 天） |

### 5.2 工具 2：名称解析预览

**纯本地字典解析，不发任何网络请求**。用于：
- 确认「名称 → adcode」解析结果（含新旧码映射、完整层级路径）；
- 排查重名歧义（如「朝阳」= 朝阳区 / 朝阳市，会列出全部候选）；
- 校验字典是否就位（找不到字典会明确报错）。

参数：行政区层级 + 名称（或 adcode，二选一，均可逗号分隔多值）。结果直接打印在消息窗口。

## 六、快速上手

| 需求 | 层级 | 名称 / 编码 | 下钻 |
|---|---|---|---|
| 中国国界 | `country` | （留空） | 0 |
| 广东省边界 | `auto` | `广东省` 或 `440000` | 0 |
| 广东省 + 21 个地级市 | `auto` | `440000` | 1 |
| 广东省 + 地级市 + 全部区县 | `auto` | `440000` | 2 |
| 全国 34 个省级（不含国界轮廓） | `country` | （留空） | 1（勾选「仅取子级」） |
| 一次多个目标 | `auto` | `山东省,河北省,河南省` | 0 |

## 七、输出说明

要素属性固定 7 个字段（名称均 ≤10 字符，SHP 安全）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `adcode` | TEXT | 行政区编码（公开主码，高德官方最新） |
| `name` | TEXT | 行政区名称 |
| `level` | TEXT | `country` / `province` / `city` / `district` |
| `parent` | TEXT | 父级 adcode |
| `children` | LONG | 直接子级数量 |
| `cen_lng` | DOUBLE | 中心点经度（WGS-84） |
| `cen_lat` | DOUBLE | 中心点纬度（WGS-84） |

> SHP 数值字段不允许 NULL，`children` / `cen_lng` / `cen_lat` 缺失时按 0 写入；
> GeoJSON 里这些字段缺失时直接不写出（保留原语义）。

## 八、常见问题（FAQ）

1. **名称 / adcode 不能混用**：一次运行二选一；多值用逗号分隔。
2. **自动推断层级**：`auto` 模式下按名称后缀（省/市/区…）或 adcode 结构（`440000`=省、`440100`=市、`440106`=区县）推断；`100000` 固定为国家。
3. **新旧编码自动切换**：按最新官方码（如崇川区 `320613`）输入时，工具自动用后端旧码 `320602` 抓取，输出回填为 `320613`，无需关心两套码差异。
4. **无边界数据（orphan）**：如新疆兵团新设的新星市（`659011`）等，DataV 后台暂无边界，工具会**明确提示并终止**，而非静默返回错误数据。
5. **歧义提示**：名称有重名（如「朝阳」）时报错并列出所有候选及层级路径，用「行政区层级」或「adcode」消除歧义。
6. **直筒子市 / 台湾**：东莞、中山等无区县、台湾无下钻数据，`depth` 下钻到这些区域自动停止，不报致命错误。
7. **南海诸岛十段线**：`100000_full` 中的特殊要素（adcode 形如 `100000_JD`）默认剔除。
8. **断点/缓存**：缓存目录参数默认关闭；只有「全国下钻 3 级」这类约 3000+ 请求的重活、或反复改参重跑时建议开启。
