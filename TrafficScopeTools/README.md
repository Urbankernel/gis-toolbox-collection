# TrafficScopeTools · 实时路况采集

从一个范围面抓取**百度 / 高德网页端实时路况瓦片**，拼接为**四级分类栅格**（畅通/缓行/拥堵/严重拥堵）+ 瓦片网格矢量。

- 数据源：百度 / 高德网页端路况瓦片（**无需 AK**）
- 输出：单波段四级分类栅格（`.tif`，带路况配色）+ 瓦片网格（`.shp`/`.gpkg`）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `TrafficScopeTools` 目录，双击 `TrafficScopeTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `TrafficScopeTools/TrafficScopeTools.pyt`。

## 参数

### 工具 1：采集实时路况

| 参数 | 说明 |
|---|---|
| 范围面要素类 | 采集范围 |
| 数据源 | 百度 / 高德 |
| 瓦片级别 | `auto` 按面积自适应，或 10~18 |
| QPS | 每秒请求数 |
| 最大重试次数 | 容错 |
| 裁剪到范围 | 只保留范围内的路况 |
| 输出路况栅格 | `.tif`（单波段分类，0=nodata，1~4 四级） |
| 输出瓦片网格 | `.shp` / `.gpkg` |
| 工作目录 | 断点续跑，可选 |

### 工具 2：干跑估算

| 参数 | 说明 |
|---|---|
| 范围面要素类 / 数据源 / 瓦片级别 / QPS | 估算瓦片数与耗时 |

## 输出

- `traffic_mosaic.tif`：单波段 uint8，值 0~4（0=nodata），内置色彩映射表（绿/黄/红/深红），ArcGIS Pro 自动用「色彩映射表」渲染
- 瓦片网格矢量：字段 `tile_id/level/tx/ty`，WGS-84

## 数据源与许可

百度/高德**网页端**路况瓦片，未公开接口、无 AK、无配额，但接口可能随前端改版失效。
