# TrafficScopeTools 使用说明

实时路况范围采集工具箱 —— 改造自开源项目 [Urbankernel/TrafficScope](https://github.com/Urbankernel/TrafficScope)，可在 ArcGIS Pro 中直接运行。

输入一个**范围面要素类**，自动切分瓦片，批量采集百度 / 高德**网页端同源**实时路况瓦片，拼接为**四级分类栅格（GeoTIFF）**，并输出**路况瓦片网格矢量**。

> **无需任何地图 AK、无配额限制**（走网页端隐藏接口，与地图网页渲染同源）。

## 一、简介

工具箱含 **2 个工具**：

| 工具 | 名称 | 作用 |
|---|---|---|
| 1 | **采集实时路况** | 范围面 → 抓瓦片 → 四级分类 → 镶嵌 → 输出栅格 + 瓦片网格 |
| 2 | **干跑估算** | 不发请求，估算瓦片数 / 预计耗时 |

## 二、环境要求

- ArcGIS Pro（arcpy 3.5.2）；
- **无需安装任何第三方库**，**无需任何地图 AK**。

## 三、目录结构

```
github_arcgis_tools/
├── geo_common/                # 共享库（coords 坐标转换 / exporter 写要素类）
└── TrafficScopeTools/
    ├── TrafficScopeTools.pyt   # 工具箱入口（2 个工具）
    ├── traffic_scope_core/     # 核心包（providers/coords/tiles/scope/cache/export/estimate/pipeline）
    └── 使用说明.md
```

## 四、在 ArcGIS Pro 中加载

用下面任一方式加载（推荐方式二）：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `TrafficScopeTools` 目录，双击 `TrafficScopeTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `TrafficScopeTools/TrafficScopeTools.pyt`。

## 五、参数说明

### 5.1 工具 1：采集实时路况

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 范围面要素类 | 要素图层（面） | ✅ | 采集范围，可从地图拖入图层或浏览选文件 |
| 数据源 | 下拉 | ✅ | `amap`（高德，默认）/ `baidu`（百度） |
| 瓦片级别 | 文本 | ✅ | `auto`（按面积自适应）或 10–18 整数 |
| QPS（每秒请求数） | 数值 | ✅ | 限速，默认 5.0 |
| 最大重试次数 | 整数 | 否 | 单瓦片失败重试，默认 3 |
| 裁剪到范围 | 布尔 | 否 | 镶嵌图是否裁剪到范围面内，默认是 |
| 输出路况栅格 | 栅格数据集 | ✅ | `.tif` 路径 |
| 输出瓦片网格 | 要素类 | ✅ | `.shp` / `.gpkg` 路径 |
| 工作目录（断点续跑） | 文件夹 | 否 | 留空自动创建；填上次目录可续跑 |

**数据源怎么选**：

| 数据源 | 地图 | 瓦片网格 | level 范围 | 说明 |
|---|---|---|---|---|
| `amap`（默认） | 高德 www.amap.com | 标准 Web 墨卡托 XYZ（GCJ-02） | 10–18 | 原始瓦片无白描边、更纯净 |
| `baidu` | 百度 map.baidu.com | 官方 BD09MC（分带多项式） | 12–18 | 实测路网最密 |

**瓦片级别（level）怎么选**：

| level | 适用 |
|---|---|
| 低级别（百度 12–13 / 高德 10–11） | 大范围（全市/全区）概览 |
| 中级别（14–15） | 区县/片区 |
| 高级别（16–17） | 中小范围精细研究，含次干道/支路 |
| 18 | 仅提几何分辨率，瓦片数会很多 |

**level 越高路网越密**。默认 `auto` 按范围面积自适应：≤25 km²→17、25–200 km²→16、>200 km²→15（高德同面积比百度低 1 级）。

### 5.2 工具 2：干跑估算

参数：范围面要素类、数据源、瓦片级别、QPS。

不发起任何请求，输出瓦片数、预计耗时。建议**先跑估算再正式采集**，确认瓦片规模。

## 六、快速上手

1. 准备一个范围面要素类；
2. 先跑「干跑估算」，确认瓦片数 / 预计耗时在可接受范围；
3. 再跑「采集实时路况」，范围面选同一要素类，输出栅格 + 瓦片网格路径填好；
4. 运行；中断后把「工作目录」指向上次目录即可续跑。

## 七、输出说明

### 1. 路况栅格（核心成果）

单波段分类栅格（`uint8`，EPSG:4326，nodata=0），按像素值分级设色：

| 像素值 | 含义 | 百度 RGB | 高德 RGB |
|---|---|---|---|
| 1 | 畅通 | (79, 210, 125) | (51, 177, 0) |
| 2 | 缓行 | (255, 208, 69) | (255, 204, 0) |
| 3 | 拥堵 | (232, 14, 14) | (222, 0, 0) |
| 4 | 严重拥堵 | (181, 0, 0) | (150, 20, 20) |
| 0 | 无数据 | 透明 | 透明 |

栅格已内置调色板，ArcGIS Pro 加载后自动按四级设色。

### 2. 路况瓦片网格（质检）

面要素类，字段 `tile_id` / `level` / `tx` / `ty`，用于检查是否有漏抓瓦片。

### 3. 工作目录（断点续跑用）

自动生成（或你指定）的工作目录内含：
- `progress.csv` —— 瓦片级进度（断点续跑依据）
- `raw/` —— 原始瓦片 PNG 存档
- `metadata.json` —— 采样时刻等元数据

中断后重跑时，把「工作目录」参数指向上次的目录，已完成瓦片直接读存档、不重复请求，只补采失败瓦片。

## 八、常见问题（FAQ）

1. **仅限自用研究**：百度/高德路况瓦片均为地图厂商**未公开接口**，仅限自用研究，**禁止批量抓取、再分发与商用**。
2. **分钟级快照**：路况是实时快照，同一范围不同时刻结果不同，成果请标注 `metadata.json` 中的采样时刻。
3. **不含速度与路名**：栅格只含四级拥堵着色，不含 km/h 速度与道路名。
4. **坐标系**：输入范围面要素类会被自动投影到 WGS-84（EPSG:4326），成果一律 WGS-84。
5. **数据合规**：路况数据权属相应地图厂商，公开研究成果请注明数据来源与采样时刻。
