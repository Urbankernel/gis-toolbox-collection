# AMapPOITools · 高德 POI 抓取

从高德地图批量抓取兴趣点（POI），支持**行政区 / 圆形缓冲 / 经纬度矩形 / 本地矢量文件**四种范围检索，用递归四分网格绕过接口单次条数上限，多 Key 轮换与断点续跑。

- 数据源：高德 Web 服务 API（**需自备 Key**）
- 输出：POI 点 + 网格面 + 范围面三图层（`.shp` / `.gpkg`）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `AMapPOITools` 目录，双击 `AMapPOITools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `AMapPOITools/AMapPOITools.pyt`。

## 参数

| 参数 | 说明 |
|---|---|
| 范围类型 | `行政区` / `圆形缓冲` / `矩形` / `本地矢量文件` |
| 范围面要素 | 本地矢量文件模式的范围面 |
| 行政区 | adcode 或名称 |
| 中心点（经度,纬度） | 圆形缓冲模式 |
| 输入坐标类型 | wgs84 / gcj02 / bd09 |
| 缓冲半径（公里） | 圆形缓冲模式 |
| 矩形范围 | `xmin,ymin,xmax,ymax` |
| 高德 Web 服务 Key | 多 Key 用分号分隔 |
| POI 类型编码 | 逗号分隔，留空则不限类型 |
| 返回字段级别 | base / all |
| 初始网格边长（度） | 递归四分起始边长 |
| 四分裂阈值（条） | 单网格超此数则分裂 |
| 最大递归深度 | 分裂上限 |
| 最小网格边长（度） | 停止分裂下限 |
| 每页条数 | 1~25 |
| 每秒请求数上限 / 最大重试 / 超时 | 限速与容错 |
| 按范围过滤界外点 | 只留范围内的点 |
| 输出要素类 | `.shp` / `.gpkg` |
| 输出坐标系 | 默认 WGS-84，可投影 |
| 断点续跑 | 勾选后重跑跳过已完成网格 |

## 输出

- `pois` 点图层 + `pois_grid` 网格面 + `pois_area` 范围面（GPKG 为同文件多图层）
- 编码字段（`poi_type_code`/`adcode`/`pcode` 等）均为 TEXT，防止前导 0 丢失
- 坐标统一 WGS-84

## 数据源与许可

高德 Web 服务 API，需自备 Key。个人开发者有日配额与 QPS 限制，商用需企业认证。
