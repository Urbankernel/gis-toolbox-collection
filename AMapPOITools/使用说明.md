# 高德 POI 抓取工具箱（AMapPOITools）使用说明

## 一、简介

**本工具箱在 ArcGIS Pro 中以图形界面方式，按空间范围批量抓取高德地图兴趣点（POI），输出为点要素类（SHP / GeoPackage）**。

核心能力：

- **四种范围定义方式**：面要素 / 行政区 / 圆形缓冲区 / 矩形范围；
- **递归四分网格**：自动把大范围切成小网格逐格检索，绕过接口「单次最多返回条数」上限，抓全范围；
- **多 Key 轮换 + 限流**：支持同时填多个高德 Web 服务 Key，自动轮换与限流重试，规避配额与频率限制；
- **断点续跑**：中断后可基于既有结果继续追加，不重复抓取；
- **统一 WGS-84** 输出。

## 二、环境要求

| 依赖 | 说明 |
| --- | --- |
| ArcGIS Pro（arcgispro-py3 环境） | 自带 `arcpy`、`requests` |
| `shapely` | 需额外安装，用于网格划分、范围过滤等几何运算 |

安装 `shapely`（需在 **ArcGIS Pro 的 Python 环境**中执行，请用管理员权限打开命令行）：

```powershell
# 进入 ArcGIS Pro 自带 Python 环境
cd "C:\Program Files\ArcGIS\Pro\bin\Python\envs\arcgispro-py3"
python -m conda install shapely
```

> 注意：不要装到用户目录（`--user`）——ArcGIS Pro 后台进程不加载用户 site-packages，会导致运行时仍报 `ModuleNotFoundError: shapely`。

## 三、目录结构

工具箱采用「薄 `.pyt` + 核心包 + 共享库」结构，请保持如下相对位置，不要移动单独文件：

```
github_arcgis_tools/
├── geo_common/                 # 共享公共库（坐标转换 / Key 轮换 / 导出等）
├── AMapPOITools/
│   ├── AMapPOITools.pyt        # ← 在 ArcGIS Pro 中加载这个文件
│   └── amap_poi_core/          # 高德抓取核心包
└── GetAOITools/                # 另一个工具箱，与本工具箱相互独立
```

## 四、在 ArcGIS Pro 中加载

用下面任一方式加载（推荐方式二）：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `AMapPOITools` 目录，双击 `AMapPOITools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `AMapPOITools/AMapPOITools.pyt`。

加载后展开工具箱，双击 **「高德 POI 抓取」** 打开参数面板，填好参数点击 **运行**，进度实时显示在「地理处理 → 消息」中。

## 五、参数说明

### 5.1 范围（按「范围类型」二选一/多选切换，未用到的参数会自动置灰）

| # | 参数名 | 显示名 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | scope_type | 范围类型 | 是 | 面要素 | 四选一：`面要素` / `行政区` / `缓冲区` / `矩形范围` |
| 2 | in_features | 范围面要素 | 面要素时必填 | — | 只接受面（Polygon）要素类；多要素取并集范围 |
| 3 | admin_keyword | 行政区（adcode/名称） | 行政区时必填 | — | 如 `杭州市` 或 adcode `330100`，自动调用行政区接口取边界 |
| 4 | center_point | 中心点（经度,纬度） | 缓冲区时必填 | — | 形如 `116.397,39.908` |
| 5 | center_coord_type | 输入坐标类型 | 否 | wgs84 | 中心点/矩形的坐标类型：`wgs84` 或 `gcj02` |
| 6 | radius_km | 缓冲半径（公里） | 缓冲区时必填 | — | 以中心点为圆心的半径 |
| 7 | bbox | 矩形范围 | 矩形范围时必填 | — | `xmin,ymin,xmax,ymax`，如 `116.2,39.8,116.5,40.0` |

### 5.2 凭证

| # | 参数名 | 显示名 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| 8 | api_keys | 高德 Web 服务 Key（可多选） | 是 | 可填多个，用下拉多选或分号分隔；多个 Key 自动轮换 |

> 高德 Key 申请：前往 [高德开放平台](https://lbs.amap.com/)，创建应用并选择「Web 服务」类型，获取 Key。

### 5.3 检索

| # | 参数名 | 显示名 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 9 | poi_types | POI 类型编码（逗号分隔） | 是 | — | 高德 POI 分类编码，如 `050000`（餐饮）或 `050000,060000` |
| 10 | extensions | 返回字段级别 | 否 | all | `all` 返回完整字段，`base` 仅基础字段 |

> POI 类型编码表参考高德官方《POI 分类编码》文档：https://lbs.amap.com/api/webservice/download

### 5.4 网格与请求

| # | 参数名 | 显示名 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 11 | grid_size | 初始网格边长（度） | 0.1 | 首次划分的网格边长（约 11 公里） |
| 12 | split_threshold | 四分裂阈值（条） | 200 | 单格返回超过该数时，自动四分裂继续细分 |
| 13 | max_depth | 最大递归深度 | 4 | 四分裂的最大层数，防止无限细分 |
| 14 | min_size | 最小网格边长（度） | 0.005 | 达到该边长即停止细分（触底截断） |
| 15 | offset | 每页条数（1~25） | 20 | 高德单次请求返回条数上限为 25 |
| 16 | qps | 每秒请求数上限 | 2.0 | 控制请求频率，避免触发限流 |
| 17 | max_retries | 单请求最大重试 | 5 | 失败自动重试（指数退避） |
| 18 | timeout | 请求超时（秒） | 10.0 | 单次请求超时时间 |
| 19 | filter_by_scope | 按范围过滤界外点 | True | 勾选后剔除落在范围外的 POI（推荐保持勾选） |

### 5.5 输出

| # | 参数名 | 显示名 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 20 | output_features | 输出要素类 | 是 | — | 仅支持 `.shp` 或 `.gpkg` 扩展名，可浏览选择或手动输入路径 |
| 21 | output_crs | 输出坐标系 | 否 | GCS_WGS_1984 | 目标投影；留空/填 WGS-84 则不投影 |
| 22 | resume | 断点续跑 | 否 | False | 勾选后沿用上次结果与状态文件继续追加 |

## 六、输出说明

运行成功后会生成 **三个图层**（GPKG 格式为同一文件内的多个图层）：

| 图层 | 说明 |
| --- | --- |
| 主输出（POI 点） | 抓取到的兴趣点，坐标系 WGS-84 |
| `<输出名>_grid` | 网格面，含 `grid_id`（网格编号）、`depth`（分裂深度）、`count`（该网格 POI 数） |
| `<输出名>_area` | 实际检索的范围面，含 `name`（范围名称） |

### 6.1 POI 点属性字段（35 个）

`poi_id`、`lon_gcj02`、`lat_gcj02`（原始 GCJ-02 坐标，供校验）、`name`、`poi_type`、`poi_type_code`、`cityname`、`adname`、`address`、`pname`、`pcode`、`citycode`、`adcode`、`tel`、`alias`、`biz_type`、`parent`、`navi_poiid`、`business_area`、`tag`、`biz_rating`（评分）、`biz_cost`（人均消费）、`photo_title`、`photo_url`、`cpid`、`floor`、`truefloor`、`parking_type`、`entr_location`、`website`、`email`、`postcode`、`indoor_map`、`indoor_data`、`grid_id`（所属网格编号）。

> 编码类字段（`poi_type_code` / `adcode` / `pcode` / `citycode` 等）统一存为文本，避免前导 0 被当作数字丢弃。

### 6.2 SHP 与 GPKG 的区别

| 项目 | SHP | GPKG |
| --- | --- | --- |
| 字段名 | 超过 10 字符自动映射/截断 | 保留原字段名 |
| 文本长度 | 最长 254 字符（超出截断） | 更长（约 4000） |
| 数据结构 | 多文件（.shp/.dbf/.prj 等） | 单文件数据库 |

SHP 超长字段名映射关系：`poi_type_code→poi_code`、`business_area→biz_area`、`photo_title→photo_titl`、`parking_type→park_type`、`entr_location→entr_loc`、`indoor_data→indoor_dat`。

## 七、常见问题（FAQ）

**Q1：运行时报 `ModuleNotFoundError: shapely`？**
shapely 未装到 ArcGIS Pro 的 Python 环境，请按「二、环境要求」在管理员命令行下安装。

**Q2：运行报 `ModuleNotFoundError: geo_common`？**
目录结构被破坏或移动了文件，请恢复「三、目录结构」的相对位置（`AMapPOITools` 与 `geo_common` 必须同级）。

**Q3：结果没有落到我指定的路径？**
本工具强制前台执行以保证路径可靠。请确认「地理处理 → 选项」未强制后台；若仍异常，检查输出路径是否有写权限。

**Q4：抓到的 POI 数量偏少？**
- 检查 `poi_types` 编码是否填对；
- 范围太大时接口可能被限流，可调低 `qps`、增大 `max_retries`；
- 确认 `extensions` 设为 `all` 以返回完整结果。

**Q5：如何续跑上次中断的任务？**
保留上次的 `<输出名>_state.json` 与输出文件，勾选「断点续跑」，输出路径与上次一致即可继续追加。
