# CnemcAirTools · 空气质量数据

从中国环境监测总站按城市抓取**城市级 / 点位级**空气质量数据（AQI、PM2.5、PM10、SO₂、NO₂、CO、O₃），输出矢量点要素类 + CSV/JSON。

- 数据源：中国环境监测总站（air.cnemc.cn:18007，**无需 AK**、无配额）
- 输出：5 个 `.shp` 点要素类 + 可选 CSV/JSON（WGS-84）

## 安装加载

先按 [安装指南.md](../安装指南.md) 完成环境准备，再用下面任一方式加载本工具箱：

**方式一 · 添加文件夹连接**：在 ArcGIS Pro「目录」窗格中「添加文件夹连接」，定位到 `CnemcAirTools` 目录，双击 `CnemcAirTools.pyt` 打开。

**方式二 · 添加工具箱（推荐）**：打开 ArcGIS Pro →「目录」窗格 →「工具箱」→ 右键「添加工具箱」，选择 `CnemcAirTools/CnemcAirTools.pyt`。

## 参数

### 工具 1：获取空气质量数据

| 参数 | 说明 |
|---|---|
| 城市名 | 逗号分隔，如 `北京市,上海市` |
| 城市编码 | 逗号分隔，如 `110000,310000`（编码优先） |
| 城市清单文件 | 可选 `.txt`，每行一个名/编码 |
| 抓取城市级 | 实时 + 近 24 小时 + 近 14 天日报 |
| 抓取点位级实时 | 默认开 |
| 抓取点位近 24 小时 | 逐点位，耗时较长，默认关 |
| QPS | 每秒请求数上限，默认 1.0 |
| 输出目录 | 写 5 个 `.shp` + CSV/JSON |
| 输出 CSV / JSON | 默认开 |

### 工具 2：城市列表查询

| 参数 | 说明 |
|---|---|
| 城市名筛选 | 逗号分隔多个，任一命中即保留；留空列全国 |
| 输出城市列表 CSV | 可选，留空只在消息窗口显示 |

## 输出

输出目录下按数据集生成固定命名文件（未勾选对应抓取项时，该数据集不产出）：

| 数据集 | 内容 |
|---|---|
| `city_realtime` | 城市实时六参数 |
| `city_hour` | 城市近 24 小时 |
| `city_day` | 城市近 14 天日报 |
| `station_realtime` | 全部点位实时 |
| `station_hour` | 逐点位近 24 小时 |

- `.shp` 字段名 ≤10 字符映射（如 `station_code→stn_code`），CSV/JSON 保持原名
- 缺失值：SHP 写 0、CSV 写空串、JSON 保留 null（精确缺失语义用 CSV/JSON）
- 城市级经纬度为该市监测点位中心点（非政府驻地）

## 数据源与许可

中国环境监测总站隐藏 JSON 接口，数据为公开环境监测数据，但接口非公开。
